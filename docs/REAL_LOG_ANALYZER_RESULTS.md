# 실측 로그 pcap-analyzer 분석 결과

이 문서는 실측 로그를 **pcap-analyzer 실제 분석 파이프라인**에 입력해 생성한 결과를
날짜/TEST 디렉터리별로 기록한다. 독립 검증기의 로밍 원장만 적은 문서가 아니다.
분석기 결과와 독립 원장의 수치·이벤트 대조는
[`ROAMING_INDEPENDENT_VERIFY.md`](ROAMING_INDEPENDENT_VERIFY.md)에 별도로 남긴다.

## 결과 출처와 해석

- 분석기 원본: `tmp/test*_validation/analyzer-result.json`
- TEST14 전체 분석 원본: `tmp/test14_validation/result.json`
- TEST14 수정 후 로밍 재검증: `tmp/test14_validation/fix-validation.json`
- `tmp/`는 대용량 실측 산출물이므로 git에는 포함하지 않는다. 이 문서는 해당 JSON의
  `text_sections`, `structured.diagnosis`, `structured.eapol`,
  `structured.roaming`을 요약한 추적 문서다.
- `Ping loss` 모듈의 무선 관측 손실과 건강도에 사용한 유선 GT 손실은 다르다. 아래
  종합표의 손실은 **분석기가 판정에 실제 사용한 유선 GT**이고, 모듈 표의 Ping loss는
  무선 캡처에서 출력된 관측 건수다.
- 느린 로밍은 STA 로그가 붙으면 체감시간 150ms 초과, 로그가 없으면 pcap 전체시간
  100ms 초과 정책으로 판정한 분석기 결과다.
